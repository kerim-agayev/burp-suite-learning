1. HTTP request / response

bitdi

Bütün web hacking-in təməli. Praktika: öz saytım kmplast.az üzərində Repeater.

🔧 Öyrəndiyimiz

Request (sorğu) brauzerdən serverə gedir, response (cavab) geri gəlir. Hər ikisinin quruluşu:

# REQUEST
GET /about HTTP/2          ← method + path + versiya
Host: kmplast.az           ← header-lər
User-Agent: ...
                           ← boş sətir (header-i body-dən ayırır)
(body — varsa)

# RESPONSE
HTTP/2 200 OK              ← status code
Content-Type: text/html    ← header-lər

<html>...              ← body (səhifənin özü)
🧪 Repeater-də nə sınadıq
  • GET /about → 200 OK (səhifə var)
  • GET /bu-sehife-yoxdur → 404 (yoxdur)
  • HEAD /about → 200, amma body yox (yalnız header-lər gəlir)
  • Host header-ini silmək → 400 Bad Request (server hansı saytı istədiyini bilmir)

Səhvim: path-i Host header-inə yazdım → Cloudflare 400 qaytardı. Bu, gələcəkdə öyrənəcəyimiz Host header attacks mövzusuna körpüdür.

🧠 Yadda saxla
  • Status kodları: 2xx uğur · 3xx yönləndirmə · 4xx sənin səhvin · 5xx serverin səhvi.
  • Qızıl qayda: “Client-ə heç vaxt etibar etmə.” Brauzerdən gələn hər şey (header, body, parametr) dəyişdirilə bilər.
