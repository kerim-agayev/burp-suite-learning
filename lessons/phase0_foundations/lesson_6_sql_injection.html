  göstər              hansı cədvəl       filtr (mətn tək dırnaqda)
  • SELECT = göstər · * = bütün sütunlar
  • WHERE = filtr · AND = hər iki şərt
  • Mətn tək dırnaqda: 'Gifts'. -- = “bundan sonrasını oxuma” (şərh).
🧪 Hücum (zəif səhifə)

Server şablonu: ... WHERE category = '[SƏN]' AND released = true. Dəyər SQL mətninə yapışdırılır.

🛡️ Qorunma (təhlükəsiz səhifə)

Eyni hücum /secure/sqli?category=Gifts'-- → 0 sətir. Dəyər mətnə yapışdırılmır, parametr kimi ötürülür, ona görə Gifts'-- sadəcə mövcud olmayan bir kateqoriya adıdır.

// ⚠️ zəif   `... WHERE category = '${category}' ...`   // $queryRawUnsafe
// ✅ təhlükəsiz prisma.product.findMany({ where: { category } })
  • Qayda: istifadəçi dəyərini heç vaxt SQL mətninə yapışdırma. Həmişə parametrized query / ORM query builder.
  • Zəif səhifə xətanı və SQL-i ekranda göstərir → bu özü information disclosure-dur (gələcək mövzu).
