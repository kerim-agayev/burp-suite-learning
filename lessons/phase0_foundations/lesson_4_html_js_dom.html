🧪 Nə etdik
  • Burp HTTP history-də MIME type = HTML olan sətri seçdim (JSON olanlar Next.js-in Rsc: 1 məlumat parçalarıdır, səhifə deyil).
  • Raw-da tapdım: <title>K&amp;M Plast</title> (&amp; = Dərs 3-dəki HTML encoding!), href="/about" → “Haqqımızda”, 14 <script.
  • Clopos: Ctrl+U → yalnız <div id="root"></div>. F12 → Elements → dolu. React evi brauzerin içində JS ilə tikir.
  • Console: document.title = "kerim" → tab adı dəyişdi. F5 → geri qayıtdı (DOM dəyişikliyi müvəqqətidir və yalnız mənə aiddir).

Console-dakı xəbərdarlıq: “bilmədiyin kodu bura yapışdırma, kimliyini oğurlaya bilər” → Self-XSS: kod sənin sessiyanda işləyir və token-ini götürə bilər.

🧠 Yadda saxla
  • Burp yalnız yolda gedən məktubları görür (HTTP). Brauzerin içində JS-in sonradan etdiklərini görmür → DOM-based XSS üçün F12 və Burp brauzerindəki DOM Invader.
  • Sayt istifadəçinin <-sini &lt; ilə sarımasa → yazılan <script> hər ziyarətçinin brauzerində işləyir = XSS → token oğurlana bilər.
  • Səhifə mənbəyindəki gizli hissələr (href, <!-- şərhlər -->, JS faylları) hakerin kəşfiyyat yeridir.
