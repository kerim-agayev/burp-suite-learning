Dərs 9. Target → Site map və Scope

bitdi

Hədəfi icazəli saytlarla məhdudlaşdırmaq və səs-küyü gizlətmək. Ən vacib təhlükəsizlik vərdişi.

🔧 Nədir

Təmizlikçi yalnız bir mənzildə işləməyə icazəlidir, qonşunun qapısını açmaq olmaz. Scope = “icazəli ünvanlar siyahısı”.

HissəNədir
Site mapBurp-un gördüyü bütün saytların ağacı
ScopeO ağacdan yalnız icazəli hədəflər
🧪 Nə etdik
  1. Site map-də 4 host gördük: kmplast.az, www.kmplast.az, static.cloudflareinsights.com, localhost:3002.
  2. localhost:3002-ni Scope-a əlavə etdik.
  3. Site map və Proxy → HTTP history filtrində “Show only in-scope items” işarələdik → yalnız localhost:3002 qaldı.
  4. Burp “out-of-scope trafiki yazmağı dayandır?” soruşdu, Yes dedik. İndən belə kənar trafik history-ə düşmür. Geri qaytarmaq: Re-enable.

Bonus müşahidə: /_next/hmr (status 101) hücum deyil, Next.js dev serverinin “kod dəyişəndə səhifəni yenilə” WebSocket kanalıdır, səs-küydür.

🛡️ Niyə vacibdir
  • Hüquqi qoruma: Intruder, Repeater, skan kimi alətlər səhvən başqasının saytına dəyməsin. Qızıl qayda: yalnız icazəli hədəflər.
  • Təmizlik: reklam, analytics, fontlar yüzlərlə sətir yaradır. Scope onları gizlədir, vacib request-lər itmir.
  • Vərdiş: hər yeni hədəfə başlamazdan əvvəl ilk iş Scope. PortSwigger lablarında da yalnız *.web-security-academy.net.

Növbəti: Repeater (bir request-i dəyişib dəfələrlə göndərmək) sistemli şəkildə.
