Dərs 8. Proxy — Burp-un ürəyi

bitdi

Mərhələ 1 başladı. Brauzerlə server arasındakı trafiki tutmaq və yolda dəyişmək.

🔧 İki rejim

Siz (Burp) brauzerlə sayt arasında oturan poçtalyonsunuz. Hər request və cavab sizin əlinizdən keçir.

RejimNə edir
Intercept OFFtrafik sərbəst keçir, Burp sadəcə yazır (HTTP history). İndiyəcən belə işlədik.
Intercept ONhər request donur, siz onu dəyişib sonra buraxırsınız.

Intercept ON olanda üç düymə: Forward (buraxır) · Drop (atır) · Intercept on/off.

⚠️ İş bitəndə Intercept-i OFF et, yoxsa bütün brauzer trafiki donub qalar.

🧪 Nə etdik (öz lab saytımız)

Intercept ON ikən http://localhost:3002/vuln/sqli?category=Gifts açdıq. Request Burp-da dondu. Birinci sətri yolda dəyişdik:

GET /vuln/sqli?category=Gifts HTTP/1.1      ← brauzerin göndərmək istədiyi
GET /vuln/sqli?category=Gifts'-- HTTP/1.1   ← bizim Forward etdiyimiz

Nəticə: səhifədə normal 2 yerinə gizli 3-cü məhsul da göründü. Brauzerdəki URL hələ Gifts idi, serverə gedən isə Gifts'--.

🛡️ Niyə vacibdir · necə qorunur
  • Niyə işlədi: server brauzerə güvənir. Amma Proxy sübut etdi — client-lə server arasındakı hər şey dəyişdirilə bilər. Client-ə heç vaxt güvənmə.
  • Necə qorunur: server gələn hər dəyəri yoxlamalı / parametrized işlətməlidir (Dərs 6). Brauzerdəki JavaScript yoxlaması heç nədir — Proxy onu tam atlayır.

Növbəti: Target / Scope — hədəfi yalnız icazəli saytlarla məhdudlaşdırmaq.
