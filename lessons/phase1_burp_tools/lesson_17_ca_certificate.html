Dərs 17. CA sertifikatı — quraşdırma tərəfi

bitdi

Dərs 5-də "niyə" gördük (Burp = MITM postman). İndi "necə quraşdırılır" — Burp-un öz brauzerində avtomatik, adi brauzerdə əllə.

🔧 Sertifikatı əldə et

Proxy aktiv ikən brauzerdə http://burpsuite açılır — xüsusi lokal ünvan, Burp-un özü cavab verir, heç yerə getmir. Orada CA Certificate linki ilə faylı endirdik.

🧪 Adi brauzerə (Firefox) quraşdırmaq — nəzəri addımlar

Burp-un öz daxili brauzerində sertifikat artıq avtomatik quraşdırılıb (ona görə heç vaxt xəta görmədik). Adi Firefox-da Burp-dan keçən trafiki görmək istəsək, əllə lazımdır:

  1. about:preferences#privacy → Certificates → View Certificates
  2. Authorities tabı → Import... → endirilmiş faylı seç
  3. "Trust this CA to identify websites" işarələ
  4. Firefox-un proxy ayarını 127.0.0.1:8080-a yönləndir

Firefox-un sertifikat anbarı Windows-unkundan ayrıdır — ona görə ayrıca import lazımdır. Bu addımları real etmədik (hazırkı iş üçün məcburi deyil, Burp-un öz brauzeri kifayətdir), lazım olanda qayıdıb edə bilərik.

🛡️ Xatırlatma
  • CA sertifikatını yalnız öz cihazınızda, öz testiniz üçün quraşdırın. Başqasının cihazına quraşdırmaq onun bütün HTTPS trafikini sizə açar — bu, icazəsiz MITM olardı.
  • Dərs 5-dəki qayda keçərlidir: 🔒 (HTTPS) yalnız "yoldakı oğru" ilə bağlıdır, XSS/SQLi-dən qorumur.
