Dərs 16. Extensions / BApp Store

bitdi

Telefonun App Store-u kimi — Burp-un əsas imkanlarını genişləndirən əlavələr.

🔧 Nədir

Artıq bir extension işlədirik: Burp MCP Server (Claude ilə bağlantı üçün). BApp Store-dan daha çox faydalı əlavə qurmaq olar.

  1. Extensions → BApp Store → axtar → seç → Install.
  2. Extensions → Installed — quraşdırılanların siyahısı, checkbox ilə aç/bağla.
🧪 Nə etdik

BApp Store-dan JWT Editor quraşdırdıq — Mərhələ 4-dəki JWT attacks mövzusu üçün lazım olacaq. O zaman bir JWT token-i Burp daxilində açıb, hətta imzasını da saxta düzəldə biləcəyik (Dərs 12b-də gördüyümüz imzasız Base64 token hücumunun əsl JWT versiyası).

🛡️ Niyə vacib
  • Community Edition-da Scanner yoxdur, amma bəzi extension-lar (Logger++, Autorize) bu boşluğun bir hissəsini doldurur.
  • Ehtiyat qaydası: yalnız tanınmış, rəsmi BApp Store-dakı extension-ları quraşdır — naməlum mənbədən kod əlavə etmək risklidir.

Növbəti: CA sertifikatı (artıq Dərs 5-də görmüşük, indi quraşdırma tərəfinə baxaq).
