Dərs 20. Organizer — tapıntıları qeydlə saxlamaq

bitdi

Mərhələ 1-in sonuncu aləti. "Sübut qovluğu" — maraqlı sorğuları qeydlə saxlamaq, hesabat yazma vərdişinin başlanğıcı (bax Mərhələ 6b).

🔧 Necə işlədilir

HTTP history-də sorğu → sağ klik → Send to Organizer (Ctrl+O). Organizer tabında: Request/Response yan-yana, sağda Notes sahəsi.

🧪 Nə etdik

Dərs 12b-dəki privilege escalation tapıntımızı (/vuln/profile?token=..., saxta role:admin) Organizer-ə göndərdik, qeyd yazdıq:

Tapıntı: imzasız Base64 token-dəki "role" sahəsi dəyişdirilə bilir.
Niyə: server token-i yoxlamadan güvənir.
Necə qorunur: rol həmişə bazadan yoxlanmalıdır (bax /secure/profile).

Bu format — tapıntı / niyə / necə qorunur — elə bizim hər dərsdə işlətdiyimiz formatdır, həm də real pentest hesabatının minyatür versiyasıdır (Mərhələ 6b-də tam öyrənəcəyik: title, impact, repro steps, fix).

🛡️ Niyə vacib
  • Böyük bir test zamanı onlarla tapıntı ola bilər — Organizer-siz hamısını yadda saxlamaq mümkün deyil.
  • Qeydlər vərdişi: tapıntı tapan kimi elə o an qısa qeyd yaz (niyə, necə qorunur) — sonra hesabat yazmaq çox asanlaşır.
