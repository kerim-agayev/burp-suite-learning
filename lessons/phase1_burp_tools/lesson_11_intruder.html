Dərs 11. Intruder — çox dəyəri avtomatik sınamaq

bitdi

Repeater-də əllə bir-iki dəyər sınayırdıq. Intruder robotdur: siyahını verirsən, hamısını göndərir, cavabları cədvəldə göstərir.

🔧 Qurmaq
  1. HTTP history-də request → sağ klik → Send to Intruder (Ctrl+I).
  2. Positions: dəyişəcək sözü seçib Add § → §Gifts§ kimi işarələnir. Attack type: Sniper (bir yer).
  3. Payloads: sağdakı siyahıya dəyərləri Paste et (və ya Enter a new item + Add hər biri üçün). Payload count 0 qalmamalıdır.
  4. Start attack.

Hamısının Status-u 200 idi — Length sütunu fərqi göstərdi. Vərdiş: nəticələri Length/Status-a görə sırala, qalanlardan fərqlənən sətri tap.

🧪 Təcrübə 2 — username enumeration, yeni lab /vuln/login

Yeni lab qurduq: login səhifəsi istifadəçi adı mövcud olub-olmamasına görə fərqli mesaj qaytarır ("İstifadəçi adı tapılmadı." vs "Parol səhvdir."). /secure/login isə həmişə eyni ümumi mesajı verir.

1-ci cəhd — Length ilə: uğursuz oldu. Səbəb: səhifə yazılan adı da geri əks etdirir (input dəyəri), ona görə Length-ə iki şey qarışdı (mesajın uzunluğu + yazılan adın uzunluğu). Nəticədə mövcud olan administrator ilə mövcud olmayan bilal təsadüfən eyni Length çıxdı — yanlış siqnal.

2-ci cəhd — Grep-Match ilə (düzgün üsul): Settings → Grep - Match → axtarış sözü əlavə et. İlk cəhdimiz Azərbaycan hərfli söz (tapılmadı) uğursuz oldu — klaviatura "ı" hərfini fərqli kodla göndərdi, mətnlə tam uyğun gəlmədi. Dərs: axtarış sözünü mümkünsə ingilis hərfləri ilə seç. Parol sözü ilə işlədi:

Parolu bilmədən, yalnız mesaj fərqindən 3 real istifadəçi adını tapdıq. Real hücumda növbəti addım — bu 3 ada parol sınamaq (başqa Intruder cəhdi).

🛡️ Niyə vacib · necə qorunur
  • Niyə işlədi: server "istifadəçi yoxdur" və "parol səhvdir" üçün fərqli mesaj verdi. Bu, giriş sisteminin özü haqda məlumat sızdırmaqdır (username enumeration).
  • Necə qorunur: /secure/login-da gördük — hər iki halda eyni ümumi mesaj: "İstifadəçi adı və ya parol səhvdir." Cavabın məzmunu, ölçüsü və vaxtı fərqlənməməlidir.
  • Grep-Match vərdişi: Length-ə güvənmə, mümkünsə mətndə konkret söz axtar; o sözü ingilis hərfləri ilə seç ki, klaviatura/kodlaşdırma problemi olmasın.

Növbəti: Decoder.
