🧪 Nə etdik

Logger-i Tool sütununa görə sıraladıq. Görünən mənbələr: Proxy, Target, Repeater, Intruder, və Extensions.

Extensions — Claude-un MCP (Burp MCP Server extension) ilə özü göndərdiyi sorğulardır (məs. Dərs 12b-də /vuln/profile-ı yoxlayanda). Çünki Burp MCP Server bir extension kimi quraşdırılıb, onun trafiki ayrıca "MCP" yox, "Extensions" kateqoriyasında görünür.

🛡️ Niyə vacib
  • Mənbə izləmə: "bu sorğu haradan gəldi?" sualına Logger-in Tool sütunu dəqiq cavab verir — əllə (Proxy/Repeater/Intruder) yoxsa Claude-un özü (Extensions) göndərib.
  • Böyük testlərdə hansı alətin nə qədər trafik yaratdığını görmək üçün faydalıdır (məs. Intruder-in neçə sorğu göndərdiyini yoxlamaq).

Növbəti: Sequencer (token təsadüfiliyi).
