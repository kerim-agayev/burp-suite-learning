Dərs 19. Bambdas — kodla filtr

bitdi

Adi filtr (checkbox-lar) məhduddur. Bambda ilə öz şərtini kiçik bir kod sətri kimi yazırsan.

🔧 Necə açılır

Proxy → HTTP history → filtr ikonu → açılan pəncərədə "Script mode" tabı (əvvəl "Settings mode" ilə yanaşı). Orada bir funksiya yazılır, nəticəsi true/false olmalıdır — true olan sətirlər göstərilir.

🧪 Nə etdik
return requestResponse.request().path().contains("/vuln/login") && requestResponse.response().statusCode() == 200;

Nəticə: yalnız /vuln/login yoluna gedən, 200 cavablı sətirlər qaldı. Checkbox-larla bu qədər konkret şərt qurmaq mümkün deyildi.

🛡️ Niyə vacib
  • Böyük tarixçədə (yüzlərlə sətir) konkret bir nümunəni (məs. "yalnız 500 xətaları", "yalnız admin sözü keçən cavablar") tapmaq üçün sürətli üsuldur.
  • Filtri işini bitirdikdən sonra təmizləməyi unutma, yoxsa sonrakı sorğular "görünmür" deyə çaşarsan.

Növbəti (sonuncu): Organizer.
