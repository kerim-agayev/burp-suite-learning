Dərs 18. Match and replace — avtomatik dəyişiklik

bitdi

Dərs 8-də Intercept ilə əllə dəyişirdik. Bu, elə onu — avtomatlaşdırılmış formada.

🔧 Necə qurulur

Proxy → Settings → HTTP match and replace rules → Add. Sahələr: Type (Request line / header), Match (axtarılan mətn), Replace (yeni mətn). Qayda Intercept-dən asılı deyil — açıq olsun-olmasın, hər uyğun request/cavabı avtomatik dəyişir.

🧪 Nə etdik

Qayda: category=Gifts → category=Gifts'-- (Request line).

Qayda/vuln/sqli?category=Gifts nəticəsi
Enabled3 məhsul (gizli də sızdı, brauzer hələ "Gifts" yazırdı)
Unchecked (söndürülüb)2 məhsul (normal davranış)

Fərq yalnız qaydadan asılı idi — sübut: eyni URL, qayda aktiv/deaktiv, nəticə dəyişdi.

🛡️ Diqqət və istifadə sahələri
  • Diqqət: qaydanı iş bitəndə söndür/sil, yoxsa bütün gələcək sorğularını səssizcə dəyişər, özünü çaşdırarsan.
  • Real istifadə: hər sorğuya test başlığı əlavə etmək, köhnə token-i avtomatik yeniləmək, bir parametri bütün sorğularda sınamaq — tək-tək Repeater-dən sürətlidir.

Növbəti: Bambdas (kiçik filtr skriptləri).
