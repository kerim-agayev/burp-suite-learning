Dərs 28. Path traversal — qovluqdan çıxıb başqa fayl oxumaq

bitdi

Mərhələ 2, mövzu #3. Giriş nöqtəsi: URL parametri (?file=). Lab: /vuln/traversal · /secure/traversal.

🔧 Bənzətmə

Bina idarəçisi "sənə yalnız öz mənzilinə giriş verirəm" deyir, amma qovluq adını yoxlamadan qəbul edir. ../qonşu-mənzil/ yazsan — "bir pillə yuxarı çıx, sonra qonşuya gir" demiş olursan.

🧪 Nə etdik
  1. /vuln/traversal?file=logo.png → normal, public/images/logo.png oxundu.
  2. public/images/ kök qovluqdan 2 pillə aşağıdadır. Kökə çıxmaq üçün 2 dəfə ../ lazımdır: ?file=../../secret.txt.
  3. Nəticə: kökdəki secret.txt (saxta "sirr") sızdı — images/ qovluğundan tamamilə kənar bir fayl.

Niyə işlədi: server file dəyərini birbaşa qovluq yoluna yapışdırdı (path.join(imagesDir, file)), ../ işarələrini təmizləmədi.

⚠️ Diqqət: real .env faylına BU ÜSULLA GETMƏ — orada əsl Neon açarımız var. Lab yalnız saxta secret.txt ilə işləyir.

🛡️ Qorunma

/secure/traversal-da eyni hücum → "Xəta: fayl tapılmadı".

  • Qayda: path.basename(file) — bu funksiya yolun yalnız son hissəsini (fayl adını) götürür, / və .. işarələrini atır. ../../secret.txt yazsan, server onu sadəcə secret.txt adlı fayl kimi oxumağa cəhd edir — images/ qovluğunda belə fayl olmadığı üçün xəta.
  • Nəticə həmişə icazəli qovluğun içində qalır, nə yazsan da kənara çıxa bilmirsən.
